Build Your Own AI Agent

A step-by-step curriculum to building AI agents from scratch in Python.

1. Basic Agent Loop

Learn the fundamental chat loop: taking user input, sending it to the LLM, and printing the response.

2. Tool Usage

Give your agent abilities by teaching it to call Python functions and use external tools.

3. Planning System

Enable multi-step problem solving by introducing a plan-making and updating mechanism.

4. Memory & Context

Manage context windows effectively by implementing summarization and long-term memory.

5. Permissions System

Add safety by requiring human approval (a safety gate) before the agent executes sensitive actions.

6. Agent Teams

Coordinate multiple specialized agents, like a Manager and a Worker, to tackle complex tasks.

7. Background Tasks

Run agent operations asynchronously while keeping the user updated on progress.

Inspired by Claude Code and modern AI engineering practices.
